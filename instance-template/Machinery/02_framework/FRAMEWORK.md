# Framework — how this sandbox operates

> Generic operating rules; no domain content.

## 1. The loop
Every task runs: **ORIENT → EXPLORE → NOTICE → REASON → PROPOSE → GATED → REVIEW → LEARN** (with forget list).
ORIENT = Grasp → Judge depth → Sharpen → Pré-vol → Jump (see AGENT_CORE §1).

## 2. Three trust domains
| Domain | Who | What |
|---|---|---|
| PROPOSE | agent | staged, typed, evidence-backed artifacts; purpose nodes only |
| VERIFY | deterministic gates | numbers recomputed, claims checked, structure validated |
| DISPOSE | the user | reason-coded verdicts on every proposal |

## 3. Working rules
- Purpose chain: every artifact cites the mission in `00_purpose/PURPOSE.md`.
- No magic claims: numbers computed or cited (method + params); judgments carry confidence + scope.
- Ask on collision, not habit. Later does not exist. Degradation is visible.
- Sandbox scope: this workspace; extended only by user-opened doors.

## 4. Artifact types
`00_purpose/` · `02_framework/` · `03_logs/` (DECISION_LOG, ROUND_LOG) · `_archive/`.

## 5. Disposition reason codes
`mission-received` · `commit` · `edit` · `park` · `clear` · `verified` · `rejected` · `user-directive` · `evidence-weak` · `pending-disposition`
